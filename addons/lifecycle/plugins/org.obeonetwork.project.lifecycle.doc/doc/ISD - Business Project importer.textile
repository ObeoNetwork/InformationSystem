h1(#business_project_importer). ISD - Business Project importer

h2(#presentation). Présentation

Dans le cadre d’IS Designer, les équipes MOA et MOE travaillent sur des projets différents et des modèles différents.
L'équipe MOE a néanmoins besoin des modèles réalisés par l'équipe MOA pour travailler.
Les cycles de vie des projets MOA et MOE pouvant être décalés, il est intéressant de bénéficier d'une fonctionnalité permettant d'importer le contenu d'un projet MOA dans un projet MOE. Ainsi, l'équipe MOE peut travailler sur une version stable des spécifications.

La fonctionnalité _Business project import_ permet justement d'importer, dans un projet, les modèles réalisés dans un projet MOA. Les modèles qui seront importés sont les modèles de type :
* _Graal_,
* _Entity_,
* _Requirement_.

Les modèles MOA sont importés au sein d'un répertoire @analysis@ créé dans le projet MOE. Les modèles précédemment importés sont écrasés et remplacés par la nouvelle version.

L'équipe MOE n'a pas vocation à modifier les modèles inclus dans le répertoire @analysis@. Si des modifications ont été faites, elles seront supprimées au prochain import.
Il existe néanmoins une exception à cette règle : les exigences provenant de l'équipe MOA peuvent être rattachées à des éléments modélisés par l'équipe MOE. L'équipe MOE peut donc ajouter des liens de ces exigences vers ses propres modèles, ces liens seront conservés lors de l'import suivant.

h3(#situation_depart). Situation de départ

L'exemple suivant utilise un projet MOA contenant un modèle _Graal_ et un modèle _Requirement_, et un projet MOE encore vide.

h3(#wizard_opening). Ouverture de l'assistant

Pour lancer l'import métier, ouvrir le menu contextuel d'un projet et sélectionner _Import..._ :

!pics/businessproject/ProjectContextMenu-Import.png!

Sélectionner _Import business project_ dans la catégorie _IS Designer_.

!{max-width:100%}pics/businessproject/ImportWizard-BusinessProjectSelection.png!

h3(#project_selection). Choix des projets

Choisir le projet MOA (_Import project_) et le projet MOE (_into project_) en utilisant les boutons _Choose..._.
Quand l'import a été lancé en ayant sélectionné le projet MOE, celui-ci est déjà pré-renseigné dans l'assistant.

!{max-width:100%}pics/businessproject/BusinessProjectImportWizard-SourceAndTargetProjects.png!

!{max-width:100%}pics/businessproject/ModelingProjectSelectionDialog-SourceProject.png!

h3(#import_execution). Exécution de l'import

Une fois les deux projets spécifiés, cliquer sur _Finish_ pour lancer l'import.
Un message d'avertissement prévient l'utilisateur que les modèles qu'il avait précédemment importés vont être complètement remplacés par les nouvelles versions. Il est encore possible d'annuler l'import à ce moment.

!{max-width:100%}pics/businessproject/BusinessProjectImportWizard-ReplacementConfirmation.png!

Un message avertit l'utilisateur que l'import a été correctement réalisé.

!{max-width:100%}pics/businessproject/BusinessProjectImportWizard-ImportSuccess.png!

h2(#import_result). Résultat de l'import

Les modèles du projet MOA sont importés dans un répertoire @analysis@ (modèles _Graal_, _Requirement_ et _Entity_).
Les diagrammes sont également importés et les points de vue correspondants sont automatiquement activés sur le projet MOE.

!pics/businessproject/ModelExplorer-ImportedAnalysisModels.png!

h2(#subsequent_imports). Imports suivants

Lancer les imports suivants de la même manière que le premier import.

Pour que l'import s'exécute, le projet MOE doit être sauvegardé et toutes les représentations (diagrammes, tableaux et arbres) doivent être fermées. Si ce n'est pas le cas, un message avertit l'utilisateur que le projet MOE va être sauvegardé et les éditeurs fermés.

!pics/businessproject/BusinessProjectImportDialog-SaveAndCloseWarning.png!

Les modèles provenant du projet MOA ne doivent pas être modifiés par l'équipe MOE. La seule exception concerne les exigences qu'il est possible d'associer à des éléments de l'équipe MOE. Ces liens ajoutés seront conservés au prochain import. Dans le cas où des éléments des modèles MOE référencent des éléments des modèles MOA, une boîte de dialogue affiche les références concernées, ces références seront supprimées au moment de l'import. L'utilisateur peut encore annuler l'import à ce moment.

!pics/businessproject/ImportReferencesWarningDialog.png!
