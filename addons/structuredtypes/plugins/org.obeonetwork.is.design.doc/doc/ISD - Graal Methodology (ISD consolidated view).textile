h1(#graal_consolidated_view). ISD - Graal Methodology (ISD consolidated view)

h2(#presentation). Présentation

Le point de vue _Graal Methodology (ISD consolidated view)_ fournit une table permettant de faciliter la saisie d'informations sur le stockage physique des classes participantes Graal.
Les informations sont stockées sous la forme d'annotations.

h2(#table_creation). Création de la table Domain Classes Annotations

Pour créer une table _Domain Classes Annotations_, activer le point de vue _Graal Methodology (ISD consolidated view)_ via le menu contextuel _Viewpoints Selection_ sur le projet ou sur le fichier @.aird@.

Une fois le point de vue activé, il est possible de créer une nouvelle table sur un objet Graal de type _System_.
À noter qu'à la première activation du point de vue, une table est créée automatiquement pour chaque objet Graal de type _System_ dans le projet.

h2(#table_editing). Contenu et édition de la table

!pics/graalconsolidated/DomainClassesAnnotationsTable.png!

Chaque package, classe participante, attribut et référence est affiché dans la colonne de gauche sous une forme arborescente.

La table comporte quatre colonnes : _Size_, _Check_, _Unique_ et _Default_.

* _Size_ : spécifie une contrainte de taille. Utilisée pour un attribut généralement en donnant une valeur numérique.
* _Check_ : spécifie une contrainte. Texte libre.
* _Unique_ : spécifie si un attribut fait partie d'un index d'unicité. Une valeur vide signifie que l'attribut ne fait pas partie d'un index. La valeur @ASC@ indique que l'attribut fait partie d'un index et que les valeurs sont triées en ordre ascendant, la valeur @DESC@ indique que l'attribut fait partie d'un index et que les valeurs sont triées en ordre descendant.
* _Default_ : spécifie une valeur par défaut. Texte libre.

La modification des valeurs se fait par édition directe des cellules du tableau.
