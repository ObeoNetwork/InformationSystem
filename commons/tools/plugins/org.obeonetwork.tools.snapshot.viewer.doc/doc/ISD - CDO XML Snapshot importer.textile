h1(#cdo_xml_snapshot_importer). ISD - CDO XML Snapshot Importer

h2(#overview). Overview

A CDO server, such as the one provided by Obeo Designer Team, can export the contents of a repository in XML format.

Reading a CDO XML snapshot without the importer requires creating a CDO server, loading the file into it and importing a project into the workspace from Obeo Designer Team.

The CDO XML Snapshot Importer performs these steps automatically. Select an XML file and a project to import. The importer creates the local project and manages the embedded CDO server in the background.

h2(#snapshot_creation). Create a CDO XML snapshot

To create a snapshot, enter the following command in the CDO server console. Replace @<repository-name>@ with the name of the repository to export and @<filename>@ with the path to the XML file to create:

bc. cdo export <repository-name> <filename>

h2(#importer_usage). Use the importer

h3(#importer_opening). Open the importer

Open the importer from the menu:

bq. _File > Import... > Sirius > Import project from CDO XML snapshot_

!{max-width:100%}pics/cdoxmlsnapshot/ImportWizard-CDOXMLSnapshotSelection.png!

h3(#snapshot_loading). Load the snapshot and select a project

In the wizard, use _Load file..._ to select an XML snapshot file. The file is automatically loaded into a newly created embedded CDO server.

The _Remote project_ list is populated with the projects in the repository, and the first project is selected.

A _Local project name_ is suggested from the remote project name. If a project with this name already exists in the workspace, an error message is displayed. Enter a valid local project name to complete the wizard.

!{max-width:100%}pics/cdoxmlsnapshot/SnapshotImportWizard-ProjectSelection.png!

h3(#import_result). Import result

Complete the wizard to create a modeling project in the workspace.
