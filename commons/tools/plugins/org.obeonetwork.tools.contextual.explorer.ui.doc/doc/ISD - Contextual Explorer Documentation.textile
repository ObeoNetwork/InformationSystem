h1. ISD - Contextual Explorer

La vue _Contextual Explorer_ est une vue utilisée principalement pour donner des informations contextuelles en affichant les relations entre les éléments d'un projet.
Cette vue est disponible depuis la version ISD 1.9.

La documentation du Contextual Explorer est disponible à cette adresse : "https://wiki.eclipse.org/ModelingAmalgam/ContextualExplorer":https://wiki.eclipse.org/ModelingAmalgam/ContextualExplorer

h2. Vue Contextual Explorer

L'affichage de la vue _Contextual Explorer_ se fait via le menu :

bq. Window > Show View > Other... > Contextual Explorer (Catégorie Amalgam)

!{width:1200px}pics/Simple_contextual_explorer.png!

La vue Contextual Explorer est divisée en trois zones verticales. La zone du milieu affiche l'élément sélectionné ainsi que les représentations dans lesquelles l'élément sélectionné apparaît. La zone de gauche affiche les éléments qui font référence à l'élément affiché dans la zone centrale. La zone de droite affiche les éléments référencés par l'élément affiché dans la zone centrale. Les différents éléments à afficher sont triés dans différentes catégories pour une meilleure lisibilité.

h3. Catégories

Lorsque l'élément sélectionné est un élément des métamodèles _Database_ ou _Environment_ (à l'exception des métadonnées) :
La zone de gauche peut afficher les catégories :
- "All direct references" sous laquelle s'affichent tous les éléments qui font référence à l'élément sélectionné.
- "Requirements" sous laquelle s'affichent les exigences de l'élément sélectionné.

!{width:1200px}pics/Contextual_explorer_with_requirement.png!

La zone de droite peut afficher les catégories :
- "All direct references" sous laquelle s'affichent tous les éléments référencés par l'élément sélectionné.
- "Metadata" sous laquelle s'affichent les métadonnées attachées à l'élément sélectionné.

!{width:1200px}pics/Contextual_explorer_with_metadata.png!

Lorsque l'élément sélectionné est un _Requirement_ :
La zone de droite peut afficher les catégories :
- "All direct references" sous laquelle s'affichent tous les éléments qui font référence à l'élément sélectionné à l'exception des éléments sur lesquels s'applique l'exigence.
- "References" sous laquelle s'affichent les éléments sur lesquels s'applique l'exigence.

!{width:1200px}pics/Contextual_explorer_with_requirement_selected.png!

Lorsque l'élément sélectionné est une catégorie (du métamodèle _Requirement_) ou un _Repository_ :
La zone de gauche peut afficher les catégories :
- "All direct references" sous laquelle s'affichent tous les éléments qui font référence à l'élément sélectionné.
La zone de droite peut afficher les catégories :
- "All direct references" sous laquelle s'affichent tous les éléments référencés par l'élément sélectionné.

!{width:1200px}pics/Contextual_explorer_with_category_selected.png!

Lorsque l'élément sélectionné est une métadonnée (à l'exception des métadonnées de documentation) :
La zone de gauche peut afficher la catégorie "Container" sous laquelle s'affichent les éléments qui contiennent des métadonnées.

!{width:1200px}pics/Contextual_explorer_with_metadata_selected.png!

Lorsque l'élément sélectionné est une métadonnée de documentation, la catégorie "Container" s'affiche dans la zone de droite et non pas à gauche.

!{width:1200px}pics/Contextual_explorer_with_metadata_documentation_selected.png!

h3. Note aux développeurs

Il est possible de contribuer de nouvelles catégories ainsi que les éléments contenus en contribuant au point d'extension "org.eclipse.amalgam.explorer.contextual.core.contentProviderCategory".
