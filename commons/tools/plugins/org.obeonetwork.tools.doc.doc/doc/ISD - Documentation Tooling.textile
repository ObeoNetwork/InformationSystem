h1(#documentation_tooling). ISD - Outillage de documentation

h2(#presentation). Présentation

L'outillage de documentation d'IS Designer permet d'associer de la documentation aux modèles. La vue _Related Documentation_ permet d'ajouter, de modifier et de supprimer des liens de documentation sur les éléments de modèles.

h2(#related_documentation_view). Vue Related Documentation

h3(#view_opening). Ouverture de la vue

Ouvrir la vue _Related Documentation_ depuis le menu :

bq. _Window > Show View > Other... > Related Documentation_ (catégorie _Information System Designer_)

!{max-width:100%}pics/documentation/RelatedDocumentationView.png!

h3(#view_content). Contenu de la vue

La vue est composée d'un tableau affichant toutes les entrées de documentation liées à l'élément actuellement sélectionné dans IS Designer. La vue peut également présenter les liens de documentation des éléments contenus par la sélection actuelle. L'activation de cette fonctionnalité se fait via l'action _Show children documentation_ dans le menu de la vue.

!{max-width:100%}pics/documentation/RelatedDocumentationView-ShowChildrenMenu.png!

La vue comporte également trois actions permettant d'ajouter, d'éditer ou de supprimer un lien de documentation.

!{max-width:100%}pics/documentation/RelatedDocumentationView-Toolbar.png!

h2(#documentation_links). Gestion des liens de documentation

h3(#link_creation). Ajout d'un lien

Sélectionner l'élément auquel ajouter un lien de documentation, puis utiliser la première action de la vue.

!pics/documentation/RelatedDocumentationView-AddLinkAction.png!

Une fois lancée, l'action ouvre une boîte de dialogue permettant de saisir le nom du lien ainsi que sa référence. La référence peut être un lien web ou un fichier de l'espace de travail.

!pics/documentation/DocumentationLinkDialog-NewEntry.png!

h3(#link_edition). Édition d'un lien

Sélectionner le lien à modifier, puis utiliser la deuxième action de la vue. La boîte de dialogue d'édition du lien s'ouvre à nouveau.

!pics/documentation/RelatedDocumentationView-EditLinkAction.png!

h3(#link_deletion). Suppression d'un lien

Sélectionner les liens à supprimer, puis utiliser la troisième action de la vue.

!pics/documentation/RelatedDocumentationView-DeleteLinkAction.png!

En lançant cette action, toutes les entrées sélectionnées dans la vue seront retirées de l'élément. Une boîte de confirmation s'ouvre de façon à éviter toute erreur de manipulation.

h2(#documentation_access). Accès à la documentation

Effectuer un double-clic sur une entrée de la vue _Related Documentation_ pour ouvrir :

* un navigateur web s'il s'agit d'une entrée web,
* l'éditeur par défaut sur le fichier s'il s'agit d'un fichier de l'espace de travail.

!{max-width:100%}pics/documentation/RelatedDocumentationView-OpenWebDocumentation.png!
