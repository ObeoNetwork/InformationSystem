h1(#databinding). ISD - Outillage de databinding

h2(#presentation). Présentation

L’outillage de databinding permet de modéliser le databinding entre des structures de données.
Une structure de données est soit un type structuré (_Entity_ du modeleur Entity, _DTO_ du modeleur SOA ou _Domain class_ du modeleur Graal) soit un _ViewContainer_ du modeleur Cinematic.
L’objectif classique est de spécifier la façon dont ces structures de données vont être transformées pour convertir par exemple une _Entity_ en _DTO_.

**Pour définir un databinding entre _ViewContainer_ et les autres structures de données, il est recommandé d’utiliser la vue _View Container Mockup_.**
En effet, la vue Mockup fournit des fonctionnalités d'édition de plus haut niveau que l'éditeur de databinding.

h2(#viewpoint_activation). Activation du point de vue IS Databinding

L’outillage de databinding embarque un point de vue fournissant :

* Un diagramme permettant de créer un databinding entre deux types structurés ou entre un _ViewContainer_ et un type structuré.
* Un éditeur spécifique permettant de lier les attributs et références des types structurés entre eux ou avec les sous-éléments d’un _ViewContainer_.

Pour activer le point de vue _IS Databinding_, sur une session _Viewpoint_ ouverte, lancer le menu

bq. _Viewpoint Selection_

Choisir le point de vue _IS Databinding_.

!pics/databinding/ViewpointSelection-ISDatabinding.png!

h2(#databinding_diagram). Databinding diagram

h3(#diagram_creation). Création du diagramme

Le _Databinding diagram_ permet de créer un _Binding_ entre deux types structurés ou un _ViewContainer_ et un type structuré. Pour éditer cet objet en détail, effectuer un double-clic sur l'élément pour ouvrir l'éditeur de binding.
Ce diagramme peut être créé sur un package (_Namespace_) ou sur un _ViewContainer_ n’ayant pas comme parent un autre _ViewContainer_.

!{max-width:100%}pics/databinding/diagram/DatabindingDiagram.png!

Les éléments suivants sont affichés sur le diagramme :

* _Entity_ : entité impliquée dans un binding.
* _DTO_ : DTO impliqué dans un binding.
* _Domain class_ : classe participante impliquée dans un binding.

h3(#binding_editor_navigation). Navigation vers l'éditeur de binding

Sur un _Binding_, effectuer un double-clic ou utiliser le menu _Open_ pour ouvrir l'éditeur de binding sur l'élément sélectionné.

h2(#binding_editor). Éditeur de binding

L'éditeur de databinding est un éditeur spécifique permettant de décrire en détail le databinding entre deux structures de données. Le moyen le plus simple pour l’ouvrir est de double-cliquer sur le _Binding_ voulu sur le diagramme décrit au chapitre précédent.

!{max-width:100%}pics/databinding/editor/BindingEditor.png!

Le contexte de l'éditeur de databinding est un _BindingInfo_. L'éditeur de databinding ne permet pas d'éditer simultanément d’autres _BindingInfo_, contrairement à la vue _View Container Mockup_ du modeleur Cinematic.

h3(#editor_layout). Structure générale de l'éditeur

L'éditeur est divisé en différentes parties :

* Une vue arborescente de la première structure de données à gauche.
* Une vue arborescente du deuxième type structuré à droite.
* Une zone centrale affichant les liens entre types.
* Un bouton _Auto bind !_.
* Une zone inférieure permettant d'éditer des expressions pour convertir les valeurs.

h3(#structured_type_tree). Vue arborescente d’un type structuré

!pics/databinding/editor/BindingEditor-StructuredTypeTree.png!

Cette vue présente les données structurées ainsi que les données contenues de manière arborescente.
Dans le cas des références ou des _ViewContainer_, il est possible de les déplier pour avoir accès aux sous-éléments (types structurés ou _ViewElement_).

À partir de cette vue, sélectionner un élément à gauche ou à droite, puis effectuer un glisser-déposer sur un autre élément dans la vue opposée. Ceci crée un _BindingReference_ entre les deux éléments.

Lorsqu’un ou plusieurs éléments sont sélectionnés, les liens les concernant sont affichés de façon plus visible sur la zone centrale.

h3(#editor_central_area). Zone centrale

!{max-width:100%}pics/databinding/editor/BindingEditor-CentralArea.png!

La zone centrale permet de visualiser les liens entre éléments.

Sélectionner un ou plusieurs liens pour les rendre plus visibles. Pour effectuer une sélection multiple, maintenir la touche _Ctrl_ enfoncée.
Lorsqu’un lien est sélectionné, les éléments liés sont mis en surbrillance et le contenu de la zone inférieure est mis à jour.

Quand des liens sont sélectionnés, un appui sur la touche _Del_ permet de les supprimer après un message de confirmation.

h3(#editor_lower_area). Zone inférieure

!{max-width:100%}pics/databinding/editor/BindingEditor-ConversionExpressions.png!

La zone inférieure affiche les champs de saisie en fonction des liens sélectionnés :

* Un premier groupe affiche un champ texte pour chaque élément concerné dans la vue arborescente de gauche.
* Un deuxième groupe affiche un champ texte pour chaque élément concerné dans la vue arborescente de droite.

Les champs de saisie permettent de saisir des expressions utilisées pour décrire comment les données sont converties. Le texte saisi n’est pas interprété, c’est à l’utilisateur de choisir le pseudo-langage qui lui convient le mieux.

La zone inférieure peut être réduite ou agrandie en hauteur en sélectionnant la limite de la zone centrale juste au-dessus du bouton _Auto bind !_.

h3(#auto_bind). Bouton Auto bind !

Le bouton _Auto bind !_ permet de créer automatiquement des liens entre les éléments à gauche et à droite nommés de la même façon.
