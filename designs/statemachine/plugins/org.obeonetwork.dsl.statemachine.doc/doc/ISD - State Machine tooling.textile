h1(#ISDDiagrammesdemachinetats). ISD - Diagrammes de machine à états

h2(#presentation). Présentation

Les diagrammes de machines à états permettent de définir des machines à états sur quasiment la totalité des éléments définis dans IS Designer, **à l'exception du métamodèle Database**.

Les diagrammes de machines à états manipulent des concepts très proches des diagrammes de machines à états définis par UML.

h2(#Crationdunmodledemachinetats). Création d'un modèle de machine à états

Un assistant de création de modèles de machine à états est accessible via le menu :

bq. _File > New > Other... > State Machine Model_ (catégorie _IS Designer_)

!pics/statemachine/NewWizard-StateMachineModelSelection.png!

Cet assistant permet de définir :
* le nom du modèle à créer (l'extension du modèle est automatiquement ajoutée à la fin du nom en grisé et en italique s'il n'y a pas d'extension précisée),
* le projet ou répertoire de destination pour cette nouvelle ressource :

!pics/statemachine/ModelCreationWizard-NameAndLocation.png!

Une fois l'assistant validé, le modèle est créé.

h2(#modeler_usage). Utilisation du modeleur

h3(#Crationdundiagrammedemachinetats). Création d'un diagramme de machine à états
 
Pour créer un diagramme de machine à états, activer le point de vue _State Machine_ via le menu contextuel _Viewpoints Selection_ du projet ou du fichier @*.aird@.

Une fois le point de vue activé, sélectionner _New state machine_ dans le menu contextuel des éléments pour lesquels un diagramme de machine à états peut être créé.

!{max-width:100%}pics/statemachine/ModelExplorerContextMenu-NewStateMachine.png!

Un objet _StateMachine_ et un diagramme de machine à états sont alors créés et visibles sous l'objet sélectionné.
Il est possible de créer autant de diagrammes de machines à états que voulu pour un même objet.

!pics/statemachine/ModelExplorer-StateMachineDiagram.png!

h3(#Navigationdanslesdiagrammes). Navigation dans les diagrammes

Étant donné qu'il y a très peu de contraintes sur l'emplacement d'un diagramme de machine à états, il peut être utile d'utiliser l'arborescence par point de vue pour le retrouver, comme décrit dans le chapitre "ISD - Environment tooling":../../org.obeonetwork.dsl.environment.design.doc/doc/ISD%20-%20Environment%20tooling.html de la documentation.

h3(#lmentsaffichsetpalettedoutils). Éléments affichés et palette d'outils

Les éléments suivants sont affichés sur le diagramme :
* _InitialState_ : point de départ de la machine à états.
* _FinalState_ : point final de la machine à états.
* _State_ : état de la machine.
* _Transition_ : transition d'un état à un autre, associée à une condition.
* _Region_ : regroupement logique d'états.

Les outils fournis par la palette sont :

| !pics/statemachine/tools/StateMachineDiagramPalette-CreateInitialState.png! | Création d'un état initial. |
| !pics/statemachine/tools/StateMachineDiagramPalette-CreateFinalState.png! | Création d'un état final. |
| !pics/statemachine/tools/StateMachineDiagramPalette-CreateTransition.png! | Création d'une transition entre deux états. |
| !pics/statemachine/tools/StateMachineDiagramPalette-CreateRegion.png! | Création d'une région. |
| !pics/statemachine/tools/StateMachineDiagramPalette-CreateState.png! | Création d'un état. |
